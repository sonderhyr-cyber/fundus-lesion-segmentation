# 项目目录与下一步实验说明

## 1. 当前实验主线

正式执行链只有一套：`train.py` → `src/model/train.py` → `src/dataset.py` →
模型 → `src/model/loss.py`，最终统一由 `src/model/evaluate.py` 评测。
`hrdecoder-experiments/` 是同学交付的历史实验归档，不是本项目的新训练入口。

本轮固定 6:1:3 自定义划分：train/valid/test = 454/76/227，seed=42。
这个划分只能用于同划分内部消融，不能与采用官方 383/149/225 划分的论文数字直接比较。

本轮数据流为：

`原图+YOLO多边形 → 同步去黑边 → CLAHE+Gamma → 前景偏置patch → HRNet-W48 → 可选M2MRF跨尺度重组 → HRDecoder → 组合损失`

## 2. 顶层文件

- `AGENTS.md`：Codex/协作者必须遵守的项目约束、路径、数据和评测口径。
- `CLAUDE.md`：另一套协作环境使用的同类项目说明。
- `.gitignore`：忽略数据集、输出、虚拟环境、二进制汇报材料等大文件。
- `requirements.txt`：Python 依赖；PyTorch按本机CUDA环境单独安装，HRDecoder依赖`timm`。
- `train.py`：统一训练入口，只负责把`src/`加入导入路径并调用`src/model/train.py`。
- `audit_dataset.py`：八步数据审计，包括完整性、标签解析、mask、像素统计、重复和可视化。
- `README_SMP.md`：SMP U-Net基线的使用说明。
- `暑期一个月冲刺-研究路线与目标.md`：整月研究路线和论文目标。
- `暑期冲刺-每周TodoList.md`：按周拆分的执行清单。
- `大创项目-经费使用明细.xlsx`：项目经费记录，不参与代码运行。

## 3. 配置文件

- `configs/hrdecoder.yaml`：原HRDecoder默认配置，保持双线性特征对齐，作为历史基线配置。
- `configs/m2mrf.yaml`：独立M2MRFNet的模型宽度、变体、训练和checkpoint配置。
- `configs/experiments/hrdecoder_blackborder_613.yaml`：仅启用去黑边的对照组。
- `configs/experiments/hrdecoder_loss_combo_613.yaml`：去黑边 + 组合损失，跨尺度仍用双线性。
- `configs/experiments/hrdecoder_m2mrf_613.yaml`：去黑边 + M2MRF，损失保持Focal-Tversky。
- `configs/experiments/hrdecoder_m2mrf_combo_613.yaml`：去黑边 + M2MRF + 组合损失的完整方案。

四个新配置使用同一数据根`dataset/DDR_split_613`，并强制校验454/76/227。
每个配置使用独立checkpoint文件，避免实验互相覆盖。

## 4. 数据与通用工具（`src/`）

- `src/paths.py`：集中定义项目根、数据根、输出目录和默认checkpoint路径。
- `src/dataset.py`：唯一正式Dataset；负责YOLO多边形解析、语义mask生成、去黑边、
  CLAHE/Gamma、512缩放、几何增强、原生分辨率评测mask和前景偏置patch采样。
- `src/utils.py`：预留的通用工具模块，目前为空。
- `src/analyze_dataset.py`：统计各类像素并输出CSV和分布图。
- `src/visualize.py`：抽样显示原图、标签mask及叠加效果。
- `src/test_dataset.py`：早期Dataset检查脚本，目前为空。
- `src/test.py`：早期测试入口，目前为空。

去黑边实现会寻找最大非黑连通区域，同时裁剪图像和mask；对patch训练使用的多边形坐标
也做相同平移。mask缩放仍严格使用`cv2.INTER_NEAREST`。

## 5. 统一模型代码（`src/model/`）

- `src/model/train.py`：统一模型构建、配置读取、DataLoader、训练/验证、早停、调度器和checkpoint。
  新增`--config`参数、组合损失构建、6:1:3数量校验和预处理配置透传。
- `src/model/evaluate.py`：统一mAUPR/mDice/mIoU评测；在原图分辨率上用softmax概率累计全局PR。
  新增`--config`，保证评测使用与训练一致的M2MRF结构、数据根和去黑边设置。
- `src/model/loss.py`：Focal-Tversky、Dice、Dice+CE及新的通用`CompositeLoss`和`build_loss()`。
- `src/model/unet.py`：项目最早的自建U-Net基线。
- `src/model/predict.py`：加载自建U-Net checkpoint并输出预测可视化。
- `src/model/registry.py`：模型名到构造函数的轻量注册表；修正了HRDecoder导入路径。
- `src/model/test_aupr.py`：把流式直方图AP与scikit-learn参考实现交叉验证。
- `src/model/__init__.py`：把目录声明为Python包。

## 6. HRDecoder（`src/baselines/hrdecoder/`）

- `__init__.py`：导出`HRDecoder`。
- `backbone.py`：通过`timm`加载ImageNet预训练HRNet-W48，输出四个分辨率分支。
- `decoder.py`：720通道压缩、7×7卷积和分类层组成的FCNHead。
- `hrdecoder.py`：随机高分辨率crop辅助监督、滑窗融合和主前向流程；本轮新增可配置的
  M2MRF级联跨尺度重组，`bilinear`开关仍保留用于对照。

## 7. M2MRF（`src/models/m2mrf/`）

- `__init__.py`：导出独立M2MRFNet和可复用重组器。
- `m2mrf_module.py`：核心patch unfold → 1D瓶颈映射 → fold的多对多特征重组。
- `reassembly.py`：本轮新增的级联2× M2MRF上采样器，供HRDecoder复用。
- `backbone.py`：包含M2MRF跨分支融合的纯PyTorch HRNet及A/B/C/D变体。
- `decoder.py`：把四尺度特征对齐、拼接并输出分割logits的FCN解码头。
- `m2mrf.py`：独立M2MRFNet顶层封装。

## 8. SMP基线（`src/baselines/smp/`）

- `__init__.py`：SMP基线包入口。
- `model.py`：构建ImageNet预训练ResNet34编码器的SMP U-Net。
- `losses.py`：SMP线使用的Soft Dice和Dice+CE。
- `train.py`：SMP历史独立训练脚本。
- `evaluate.py`：SMP历史评测脚本；正式论文数字仍应使用统一`src/model/evaluate.py`复算。
- `predict.py`：SMP预测可视化。

## 13. 推荐实验顺序

1. `hrdecoder_blackborder_613`：建立去黑边后的新对照组。
2. `hrdecoder_loss_combo_613`：只测组合损失增益。
3. `hrdecoder_m2mrf_613`：只测M2MRF重组增益。
4. 前两项至少一项有效后，再跑`hrdecoder_m2mrf_combo_613`检查是否叠加。

不要先跑完整组合再解释结果；同学上一轮CE+Dice、Tversky和结构组合已有多项负结果，必须保留
单因素对照才能判断真正贡献。
